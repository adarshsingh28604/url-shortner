# URL Shortener

A simple URL Shortener web application that converts long URLs into short and easy-to-share links.

## Features

- Shorten long URLs
- Generate unique short links
- Redirect users to original URLs
- Simple and user-friendly interface

## Tech Stack

- Node.js
- Express.js
- MongoDB
- JavaScript

## Installation

1. Clone the repository

```bash
git clone git@github.com:adarshsingh28604/url-shortner.git
```

2. Install dependencies

```bash
npm install
```

3. Start the server

```bash
npm start
```
